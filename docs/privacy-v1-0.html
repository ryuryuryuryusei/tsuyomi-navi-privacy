プライバシーポリシー

最終更新日: 2026年2月13日

つよみナビ（以下「本アプリ」）は、お子さまの個性に合った習い事を提案するアプリです。本アプリをご利用いただくにあたり、以下のプライバシーポリシーを定めます。

1. 収集する情報

本アプリは以下の情報を取り扱います。

  • お子さまの情報: ニックネーム、年齢帯、性別、質問への回答（気質・才能の診断に使用）
  • 位置情報: 「近くの教室」機能を利用する際に、ユーザーの許可を得た上で取得します

2. データの保存場所

本アプリで入力されたすべてのデータはお使いの端末内にのみ保存されます。外部サーバーへの送信は行いません。アプリを削除すると、すべてのデータが消去されます。

3. 位置情報の利用

本アプリは、近くの習い事教室を検索する機能において、Apple MapKit および Google Places API を使用します。位置情報は教室検索の目的にのみ使用し、保存・送信は行いません。位置情報の利用はユーザーが明示的に許可した場合にのみ行われます。

4. 広告について

本アプリは Google AdMob を利用した広告を表示します。AdMob は広告配信のために端末の識別情報を使用する場合があります。詳細は Google のプライバシーポリシーをご確認ください。

5. 第三者への提供

本アプリは、広告配信（Google AdMob）および教室検索（Google Places API）以外の目的で、第三者にユーザー情報を提供することはありません。

6. お子さまのプライバシー

本アプリは保護者の方がお子さまの情報を入力して利用するアプリです。お子さまが直接操作することは想定していません。入力された情報は端末内にのみ保存され、外部に送信されることはありません。

7. ポリシーの変更

本ポリシーは必要に応じて更新されることがあります。変更があった場合は本ページにて公開します。
